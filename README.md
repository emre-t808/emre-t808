### The proof

**[Harness Harness](https://github.com/emre-t808/harness-harness)**
Coding agents harness LLMs. But who harnesses the coding agents? A self-improving harness for Claude Code: it scores every rule by whether the agent actually uses it, and proposes its own changes for review. Source-available, published on npm, and what I work in every day.

**[AX Designer](https://github.com/emre-t808/people-agents-and-culture/blob/main/AX-DESIGNER.md)**
My case for Agent Experience as a design discipline alongside UX and DX, with sixteen principles and a job description any team can fork.

**The work you can't see**
